# Sample image prompts

Use these as scaffolds, not mandatory templates. Remove irrelevant fields and preserve the user's wording.

## Website hero

```text
Asset type: landing-page hero image
Primary request: a handmade ceramic coffee mug on a pale stone counter
Style/medium: natural editorial product photography
Composition/framing: wide composition; mug in the right third; uncluttered negative space on the left for page copy
Lighting/mood: soft morning window light; quiet and warm
Materials/textures: matte speckled ceramic, subtle stone texture
Constraints: realistic scale; clean silhouette; no text, logo, watermark, or extra objects
```

## Product mockup

```text
Asset type: catalog product image
Primary request: show the supplied package standing upright in a minimal studio setup
Input images: Image 1 is the exact package and label reference
Composition/framing: front three-quarter view, centered, complete object visible
Lighting/mood: softbox lighting with a restrained contact shadow
Constraints: preserve package shape, label copy, colors, and proportions exactly
Avoid: invented branding, extra copy, warped text, hands, props, watermark
```

## Precise edit

```text
Asset type: product-photo edit
Primary request: replace only the background with a warm sunset gradient
Input images: Image 1 is the edit target
Change: background only
Keep unchanged: product, label, edges, position, scale, lighting direction, and framing
Avoid: text changes, new objects, halos around the product, watermark
```

## Style reference

```text
Asset type: editorial illustration
Primary request: illustrate a cyclist crossing a quiet bridge at dawn
Input images: Image 1 is a style and palette reference only; do not copy its subject or composition
Composition/framing: wide side view with the cyclist small against the landscape
Lighting/mood: misty dawn, calm and reflective
Constraints: original composition; no text, logo, or watermark
```

## Transparent cutout

```text
Asset type: transparent product cutout
Primary request: isolate the supplied object on a genuinely transparent background
Input images: Image 1 is the edit target
Keep unchanged: object shape, color, texture, and internal details
Constraints: preserve alpha transparency; clean antialiased edges; no background pixels
Avoid: checkerboard pattern, white backdrop, colored matte, halo, added shadow, text, watermark
```

## Sprite

```text
Asset type: game inventory sprite
Primary request: a small brass compass with a cracked glass face
Style/medium: hand-painted fantasy game sprite
Composition/framing: centered object, three-quarter top-down view, strong readable silhouette
Color palette: aged brass, deep teal glass, restrained warm highlights
Constraints: transparent background; no text; no border; readable at 64 by 64 pixels
```

## Iterative follow-up

```text
Change only: make the scarf deep blue.
Keep unchanged: subject identity, pose, facial expression, composition, background, lighting, and all other colors.
Avoid: new accessories, text, logo, watermark.
```
